A program that writes one original sentence about the best meal ever had (152 characters) to `/output/entry.txt` for make.fun's "The Best Meal You Ever Had" bounty. The sentence is the whole entry: one meal, standing alone — *"At 2 a.m. the cart man ladled soto ayam over rice, the broth steaming up my glasses, and I finished it standing in the rain because the bench was taken."* It scores six candidate sentences against the judge's own criteria — staying on subject, concreteness, feeling true to one person's memory, a clean sentence, a landing that stays — and writes the winner. It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
